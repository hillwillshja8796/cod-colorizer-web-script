## What it does

COD Colorizer is a web-based utility for generating colored text used in classic Call of Duty titles. It provides an easy way to assemble formatted strings for player names, binds, and server messages, so you can copy the result into older COD setups without hand-editing every color code.

The focus is on producing text output, not automating gameplay. It is intended for Call of Duty entries commonly tied to the q3-engine lineage, with references to COD1, COD2, COD4, and CODUO-style use cases. Future changes should keep the formatting predictable and simple to reuse in your own workflow.
